# Artemisinin Resistance (K13) Genomic Summary Statistics

This repository contains data analysis scripts and summary statistics for Plasmodium falciparum Kelch13 (K13) validated
gene mutations associated with artemisinin resistance across various studies in East Africa.

## Project Overview
- **Objective:** Aggregate and compute summary statistics on published studies identifying K13 mutations.
- **Dataset:** Validated K13 dataset (`K13_validated_v8.xlsx`).
- **Key Metrics:**
  - Total number of unique studies (by PMID)
  - Number of unique studies per country
  - Frequency and geographic distribution of validated mutations

## Visualizations
The analysis generates country-level distribution plots exported in multiple formats (`.png`, `.pdf`, `.tif`) suitable for publication.
